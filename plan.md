# LagerSim - Plan projektu

## Etap 1: Generator zamówień (3-4h)
- [ ] Stworzyć `orders.py`
- [ ] Zaprojektować strukturę zamówienia
- [ ] Stworzyć listę produktów i lokalizacji
- [ ] Generować losowe zamówienia
- [ ] Wyświetlać zamówienia w `main.py`

## Etap 2: Terminale (4-5h)
- [ ] Stworzyć `terminals.py`
- [ ] Dodać 10 terminali (Alfa, Bravo, Charlie...)
- [ ] Przypisać każdemu własną wydajność
- [ ] Obsłużyć przydzielanie zamówień

## Etap 3: Symulacja (6-8h)
- [ ] Stworzyć `simulation.py`
- [ ] Dodać wirtualny zegar
- [ ] Automatycznie realizować zamówienia
- [ ] Obsłużyć kolejkę i statusy zleceń
- [ ] Dodać batch i avgang

## Etap 4: Szacowanie czasu (4-6h)
- [ ] Stworzyć `estimator.py`
- [ ] Obliczać ETA zamówień
- [ ] Uwzględniać wydajność terminali
- [ ] Symulować usuwanie terminali

## Etap 5: Magazyn (4-5h)
- [ ] Stworzyć `warehouse.py`
- [ ] Dodać korytarze i lokalizacje
- [ ] Symulować utrudnienia i opóźnienia

## Etap 6: Statystyki (4-5h)
- [ ] Stworzyć `statistics.py`
- [ ] Analizować wydajność terminali
- [ ] Wykrywać najwolniejsze lokalizacje
- [ ] Porównywać ETA z rzeczywistym czasem

## Etap 7: Interfejs (5-7h)
- [ ] Stworzyć widok zamówień
- [ ] Stworzyć panel administratora
- [ ] Dodać reset i generowanie 30 zamówień
- [ ] Przetestować projekt
- [ ] Uzupełnić README.md
